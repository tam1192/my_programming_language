# 方程式
方程式とは

$$ (3+2)*2 = 3*2 + 2*2 = 6 + 4 = 10 $$
$$ (x+2)^2 = x^2 + 2^2 = x^2+4 $$

こういうのを方程式という。

この言語は方程式で構成されている。 例えば $ y = 10 $ は、 $ y $ が $ 10 $ でなければ成立しない。  
言い換えれば、この式を書いた瞬間に**文字y**は、**数値10**であることが確定する。
他言語ではこれを**代入**と言ったりする。

```js
y = 10 // yは10になった
10 = y // 逆に書いてもよい
```
(※シンタックスハイライトは、都合の良いものを使ってます (上の例だとjs))

## 文字とは
この言語は、一般的に変数と呼ばれる存在を文字といいます。  
文字は、正規表現でいう `[a-zA-Z]` と、自分自身をさす `_` のみに限られます。  
つまり、`_`含め、**文字(変数)の数は53個になります。**

## 値について
ここでは二つの値を扱います。　一つが数値、二つが式値です。

### 数値
数値とは、整数や小数を表すもので、一般的に整数型や浮動小数点型などと呼ばれます。

### 式値
式値とは、式を表すものです。　式は数値と数学的記号の組み合わせ、もしくは1つ以上の文字をいいます。
式値を計算するときは評価演算子`{}`が用いられます。 これは、式値を計算するものです。

```
10 // 数値です
x // 文字であり、式値です。
x = 10 // xが10であることを示す式値です
{x} = 10 // {x}により式 x が計算され、 10を返します。
{2 + 3} = 5 // 計算して、数値を返す例
{1 = 1} = 0 // 方程式自体も式であり、評価すると正常に計算されたかを比較できます。
{x = x} = 0 // 文字は式なので、数値を返しません。
{{x} = 10} = 10 // 評価演算子により式 x が計算され、 10を返します。
// boolは0をtrue、1をfalseとして扱います。
```
(式と数値の例)
